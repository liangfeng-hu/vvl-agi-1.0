# vvl-agi-1.0

VVL-AGI v1.0: A Verifiable Civilizational Alignment Control Framework (Paper \& Minimal Code)

This repo contains:

- `paper/main.tex` – LaTeX source of the paper  
- `civ_kernel.py` – minimal CivKernel implementation (QP + VVL + Ω-GC)  
- `toy_case_c_recommender.py` – tiny toy example for Case C (recommender governance)  
- `requirements.txt` – Python dependencies

The goal is to provide a **minimal, auditable, and runnable** skeleton of the VVL-AGI 1.0 framework.
